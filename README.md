# MUS Portfolio

This is the source code for the personal portfolio of **M. Umar Shahbaz**. Built with Jekyll, Bootstrap, and Docker, it showcases projects, skills, and more.

View the site at [m-umar.me/preview](https://m-umar.me/preview/index.html)

## 🚀 Features

- **Jekyll-powered static site** with custom plugins and layouts
- **Bootstrap 5** for responsive design
- **Docker support** for easy deployment
- **Dynamic assets** (JS, CSS) and image optimization
- **Project and timeline collections**
- **Custom Liquid includes** for cards, icons, skills, and more
- **Dual-Color elements** for showing different variants on each theme.
- **SEO, sitemap, feed, and minification plugins**

## 🗂️ Structure

- `_config.yml` — Jekyll configuration
- `_navbar_pages/` — Main site pages (Home, Projects, Resume, Timeline, etc.)
- `_projects/` — Project details
- `_data/` — Skills, icons, timeline, and more (YAML)
- `_includes/` — Reusable Liquid components
- `_layouts/` — Page layouts
- `_sass/` — SCSS styles (Bootstrap, custom, code, etc.)
- `assets/` — Images, PDFs, scripts, styles, webfonts
- `docker_build/` — Docker build output
- `_plugins/` — Custom Ruby plugins (Mermaid, Share Bar)
- `Gemfile` — Ruby dependencies

## 📦 Plugins Used

- jekyll-feed
